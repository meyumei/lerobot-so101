## 3. 训练前 Dataset Load Test

在服务器设置：

```bash
export DATASET_ROOT="$HOME/lerobot-so101/datasets/so101-right-pick-blue-box-v1-70ep"
```

测试：

```bash
python - <<'PY'
import os
from lerobot.datasets.lerobot_dataset import LeRobotDataset

root = os.environ["DATASET_ROOT"]

dataset = LeRobotDataset(
    repo_id="meyumei/so101-right-pick-blue-box-v1-70ep",
    root=root,
)

print("Episodes:", dataset.num_episodes)
print("Frames:", dataset.num_frames)
print("FPS:", dataset.fps)
print("Cameras:", dataset.meta.camera_keys)

sample = dataset[0]

for key, value in sample.items():
    if hasattr(value, "shape"):
        print(key, tuple(value.shape), getattr(value, "dtype", ""))
    else:
        print(key, type(value))

print("DATASET LOAD SUCCESS")
PY
```

`dataset[0]` 很重要，因为它会实际读取 parquet，并真正解码视频帧。
